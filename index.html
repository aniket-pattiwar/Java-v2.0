Problem Solving & Programming Concepts using Java

A rigorous, structured masterclass covering algorithmic problem solving, binary computer arithmetic, Java core fundamentals, object-oriented design patterns, enterprise I/O streams, and multithreaded concurrency.

📖 Complete 5-Unit Curriculum Breakdown

Unit 1 🔢

Problem Solving & Number System

Logical thinking, Problem-solving Process, Flowchart & Algorithm, Pseudo Code, Number Systems (Binary, Octal, Decimal, Hexadecimal), Positional Notation, Base Conversions, Binary Arithmetic, 1's & 2's Complement, Computer Arithmetic.

Unit 2 ☕

Java Basics

Introduction to Java, Features of Java, JVM / JDK / JRE Architecture & JIT Compiler, Data Types, Type Casting & Promotion, Operators, Control Statements (Selection, Iteration, Jump), Arrays (1D, 2D, Jagged), Strings (Immutability, SCP, StringBuilder).

Unit 3 🏛️

Object Oriented Programming with Java

OOP Principles, Classes & Objects, Pass by value v/s pass by reference, Static variables & methods, Cross-class access, Reference vs Primitive, Reference vs Static variables, Inheritance & Polymorphism implementation.

Unit 4 📁

Java IO and Exceptions

InputStream/OutputStream, Reader/Writer, Serialization & transient, Shallow vs Deep copy, Exception hierarchy, try-catch-finally, throws/throw, Multi-catch, Creating user defined checked & unchecked exceptions.

Unit 5 ⚡

Java Collections & Multithreading

Collection hierarchy (List, Queue, Set, Map), Collections class, Comparable/Comparator, Thread & Runnable, Deadlock, Synchronization, wait/notify/notifyAll methods.

🎯 Course Objectives & Outcomes (COs)

  • CO1: Apply problem-solving techniques to analyze requirements and develop efficient algorithmic solutions for real-world problems.
  • CO2: Design and implement Object-Oriented Programming (OOP) concepts such as classes, objects, inheritance, polymorphism, encapsulation, and abstraction using Java.
  • CO3: Develop Java applications using control structures, arrays, methods, exception handling, and file handling to create robust software solutions.
  • CO4: Build and debug modular, reusable, and maintainable programs by following industry-standard coding practices and object-oriented design principles.

// Run with: java -cp bin capstone_project.CollegeManagementSystem
public class CollegeManagementSystem {
    public static void main(String[] args) {
        StudentService service = new StudentService();
        service.registerStudent(new Student(101, "Vikram Malhotra", "vikram@univ.edu", "MCA", 8.9, 45000));
        service.registerStudent(new Student(102, "Ananya Roy", "ananya@univ.edu", "MBA", 9.6, 50000));

        // Merit Ranking via Custom Comparator
        List<Student> merit = service.getMeritList();
        merit.forEach(Student::displayProfile);

        // Concurrent Fee Payment Gateway Simulation
        Thread t1 = new Thread(() -> {
            try {
                Student s = service.getStudent(101);
                s.payFee(20000);
                service.logAudit("PAYMENT: ₹20000 by " + s.getName());
            } catch (Exception e) {}
        });
        t1.start();
    }
}
